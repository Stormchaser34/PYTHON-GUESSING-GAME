# Number Guessing Game

A simple Python number guessing game.

# How it works

- The computer randomly chooses a number between 1 and 100.
- The player enters guesses.
- The program tells the player if their guess is too high or too low.
- The game counts the number of guesses.
- The game ends when the correct number is guessed.
